# Provenance and rights

Jadon Calvert published this machine-learning project in 2026. It uses new
code to revisit the problem in his 2024 graduate coursework. He directed and
reviewed the implementation and documentation with extensive AI assistance.
The repository does not claim that he wrote every line without assistance.
It contains no copied coursework files, excerpts, or republished submissions.
The measurements reported here come from the new implementation.

The 2024 coursework archive remains private. This project does not modify it,
and the repositories share no history.

## Original work

The MIT [license](../LICENSE) covers the following original work:

- `src/nfl_showcase/` contains the feature preparation, models, and CLI,
  including the chronological evaluation protocol.
- `tests/` contains the test suite.
- `.github/workflows/ci.yml` runs the automated checks.
- `examples/` contains the three example scripts and sample prediction context.
- `docs/` contains the documentation and static report.
- `README.md` introduces the project and its commands.
- `results/` contains aggregate metrics and figures generated by those commands.

The 2024 experiment used a notebook workflow with random row-level splitting
and preprocessing fitted outside the training fold. Its reported micro-F1
of about 0.75 to 0.77 appears in the historical comparison in `experiment.md`.
Those numbers are not measurements of this code. This repository does not
regenerate them, and they are not comparable with the current results.

## Datasets

The repository does not distribute the NFL play-by-play dataset for 2009
through 2018. Kaggle lists its license as `Unknown`. The upstream data
repositories declare no data license. The dataset originated from NFL.com
scraping, and this project claims no rights or permission to reuse it.
See [data.md](data.md) for the source, acquisition steps, and verification.

`examples/classification.py` reads scikit-learn's bundled copy of the UCI
[Breast Cancer Wisconsin (Diagnostic) dataset](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic).
UCI lists it under CC BY 4.0. This repository does not distribute that dataset,
and the MIT license does not cover it. Check the UCI page and scikit-learn's
terms before reuse.

The scripts generate the regression data, blobs, and synthetic image in
`examples/`. The fictional spam/ham messages, smoke data, and test fixtures are
original to this repository. The MIT license covers them as part of the code
and analysis.

## Data rights detail

The NFL dataset's sources do not establish permission to redistribute it:

- [Kaggle's metadata](https://www.kaggle.com/api/v1/datasets/view/maxhorowitz/nflplaybyplay2009to2016)
  lists the license as `Unknown`.
- The dataset description says nflscrapR "uses an API maintained by the NFL
  to scrape, clean, parse, and output clean datasets". The R package declares
  `License: CC0` in its
  [DESCRIPTION](https://github.com/maksimhorowitz/nflscrapR/blob/master/DESCRIPTION).
  That license covers the package code, not the scraped data.
  The [companion data repository](https://github.com/ryurko/nflscrapR-data)
  has no license file, and GitHub reports no license for it.
- The expected-points and win-probability columns come from the nflscrapR
  research project. See Yurko, Ventura, and Horowitz,
  [*nflWAR: A Reproducible Method for Offensive Player Evaluation in Football*](https://arxiv.org/abs/1802.00998).
- [NFL.com's Terms and Conditions](https://www.nfl.com/legal/terms/), updated
  2024-05-16, assert NFL ownership of content and data "included or displayed
  in or through, provided with or through the use of, or generated from" its
  services. They prohibit systematic data retrieval without prior written
  consent.
- [Kaggle's Terms of Use](https://www.kaggle.com/terms) govern downloads.

Because upstream rights remain unresolved, this repository publishes only
original code and aggregate results. It does not distribute raw data, rows,
play descriptions, or player-identifying fields. It does not claim that any
particular dataset reuse is permitted.

The available sources do not establish whether the dataset publisher had
permission to redistribute scraped NFL data. The MIT license covers the
original code and analysis, which are independent of the dataset.

## Claims and metrics

The commands in this repository generate the metrics in `results/` from
the documented data and chronological, game-separated holdout. No results
are entered by hand or copied from the 2024 experiment.

The experiment does not select models using the test set. Its numbers measure
one holdout, not football prediction in general. Scores from the fictional
smoke fixture do not measure performance on real NFL data.

NFL and team names identify the dataset's contents. This project has no NFL
affiliation or endorsement and licenses no NFL marks. The public documentation,
reports, and figures contain no raw dataset rows or player-identifying data.
