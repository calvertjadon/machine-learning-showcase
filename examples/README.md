# Reference examples

These three Python scripts compare methods on small datasets and write metrics
and figures. Jadon Calvert directed their development with AI assistance in
2026. They use new code, not copies of the 2024 coursework notebooks.
The authorship statement does not claim that he wrote every line unaided.

The scripts do not import `nfl_showcase`, read course files, or use the network.
Each dataset comes with scikit-learn or is generated by the script.
The `# %%` markers use Jupytext's percent format. Editors that support this
format can run the files as cells. They also run as ordinary Python scripts.

## Questions and approach

### `linear_regression.py`

How closely do a least-squares solution, scikit-learn's `LinearRegression`,
and batch gradient descent agree on a generated noisy linear relationship?

The data has three standard-normal inputs, known coefficients, and Gaussian
noise. One seed generates 200 training rows and 100 holdout rows.
`numpy.linalg.lstsq` computes the analytical fit. The script compares its
parameters with scikit-learn's fit and an original gradient descent regressor.

Gradient descent standardizes inputs with training statistics, records loss
each epoch, and runs at several learning rates. A log-scale plot compares its
loss with the analytical training MSE. The JSON reports parameter errors,
training and holdout MSE, and holdout R² for each solver.

### `classification.py`

The script runs two separate studies.

On scikit-learn's bundled breast cancer data, it compares KNN and Gaussian
naive Bayes. Both pipelines begin with `StandardScaler`. The split preserves
class proportions. Five-fold stratified cross-validation selects `k` using
only the training split, and each fit learns its own scaler. The outputs
include accuracy, macro F1, per-class metrics, and confusion matrices.

On fictional spam and ham messages, it fits TF-IDF followed by
`MultinomialNB`. TF-IDF uses unigrams, bigrams, and sublinear term frequency.
The script reports a stratified holdout and five-fold cross-validation.
It also lists the tokens most associated with each class. The token lists and
vocabulary size come from the fit used for the holdout predictions.
Each cross-validation fit uses only its fold's training messages.
No model fits the full toy corpus.

### `clustering.py`

The first study generates blobs around four centers with a fixed seed.
It fits K-means for several values of `k`, then records inertia and silhouette.
For the generator's `k`, it compares the recovered clusters with the known
labels using the adjusted Rand index.

The second study generates an RGB image in NumPy using gradients, texture,
geometric shapes, and seeded noise. K-means reduces it to a color palette.
The script reports RMSE, MAE, PSNR, per-channel RMSE, the fraction of pixels
changed, and the byte count of an indexed palette. It uses no photograph or
third-party image.

## Measured results

The following numbers come from the JSON files in `results/examples/`,
generated with `--seed 42`. This text is a static summary, not generated
at build time. Check it against the JSON if the seed or library versions change.

### Linear regression

All three solvers give test R² 0.9213 and test MSE 1.0703 on 100 holdout rows.
Training MSE is 0.8949. The estimated coefficients are
`[2.9521, -1.9027, 0.4191]`, compared with the true `[3.0, -2.0, 0.5]`.
The maximum absolute coefficient error is 0.0973.
Pairwise maximum coefficient differences between the analytical, scikit-learn,
and gradient descent fits are 2.1e-15 and 2.4e-15, within floating-point error.
At learning rate 0.25, loss falls from 15.3842 to 0.8950 in roughly 35 of
400 epochs and then stays flat.

### Classification

The breast cancer split has 426 training rows and 143 holdout rows.
Five-fold stratified cross-validation selects KNN with `k=9`, with mean
macro-F1 0.9669. Its holdout accuracy is 0.9650 and macro-F1 is 0.9617.
Gaussian naive Bayes has accuracy 0.9371 and macro-F1 0.9317.

The TF-IDF and MultinomialNB pipeline scores 1.0 accuracy and macro-F1 on
the eight-message holdout. Five-fold cross-validation gives mean macro-F1
0.9003 ± 0.0816. This measures performance on the toy corpus, not a real
spam-filter benchmark.

### Clustering

Silhouette peaks at the generator's `k=4`, with a score of 0.8476 and inertia
492.13. The recovered clusters match the known labels, with adjusted Rand
index 1.0 and four clusters of 150 points.

The 288×192 image has 55,296 pixels and 46,822 unique colors. Reducing it to
eight colors gives RMSE 20.30, MAE 15.56, and PSNR 21.98 dB.
Quantization changes 99.99% of pixels. The indexed palette takes 20,760 bytes,
including 24 bytes for the palette, compared with 165,888 source bytes.
That gives a calculated compression ratio of 7.99×.

## Commands

Run from the repository root after `uv sync --locked`:

```bash
uv run python examples/linear_regression.py --output-dir results/examples
uv run python examples/classification.py --output-dir results/examples
uv run python examples/clustering.py --output-dir results/examples
```

Each script runs independently. `--output-dir` defaults to `results/examples`.
`--seed` defaults to `42`; change it to generate a different dataset or split.
The scripts use hundreds of samples and one small image, so a laptop CPU
is sufficient.

## How the measurements are produced

All random data, splits, folds, and K-means restarts use the recorded seed.
Learned transforms use only the training rows of each fit. The toy token
lists come from the holdout model's training fit, and cross-validation refits
the model within each training fold. The JSON files record these rules.

The same seed and library versions reproduce the JSON and figures.
The scripts use matplotlib's Agg backend to write PNG files without a display.
Each prints its scores and output paths.

## Limitations

The regression example compares solvers on one well-conditioned synthetic
dataset with Gaussian noise. It does not compare modeling strategies or
measure performance on real regression data.

The breast cancer scores describe one stratified split. Cross-validation
selects KNN's neighbor count within its training split. These measurements
do not describe every possible split of the dataset. Gaussian naive Bayes
is scale invariant; the scaler keeps the two pipelines consistent.

The fictional messages demonstrate TF-IDF and multinomial naive Bayes
on a small sample. Their scores do not establish spam-filter quality
and must not be compared with published SMS benchmarks.

The clustering study uses separated blobs and a synthetic image. Image error
depends on this scene, its noise, and the palette size. The compression ratio
is a calculation for an indexed palette, not a measurement of file sizes.

Library versions can change estimator results. The `environment` field
is part of each recorded result.

`sklearn.datasets.load_breast_cancer` loads scikit-learn's bundled copy without
a download. The source is UCI's
[Breast Cancer Wisconsin (Diagnostic) dataset](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic),

at the University of Wisconsin. UCI lists it under CC BY 4.0.
This repository does not distribute the dataset, and its MIT license
does not cover it.

The toy messages are fictional text written for this project.
The scripts generate the blobs, linear data, and image from the recorded seed.
They include no course handouts, instructor notebooks, third-party figures,
real messages, or photographs.
